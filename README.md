# Portfolio Website

Personal site for Swaminathan Sankaran — <https://www.swaminathansankaran.com>

No build step, no dependencies: plain HTML, CSS and vanilla JavaScript, with WebGL for
the figures (and a 2D-canvas fallback).

## The idea

The whole page is drawn with 8,760 points, one for every hour of US electricity demand
in 2025. They open as a 3D surface of that year, and as you scroll the same points
spring into each project's figures: a heat map of the year, a bubble chart of 53 grid
operators, California ISO's average day being corrected, the retraining loop, a stack
of CT slices folding into one image, and a portrait at the end.

## Local preview

From this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

The live site is hosted on **Vercel**, connected to this GitHub repository.
Pushing to `main` deploys to production; pushing any other branch creates a
preview deployment. There is no build command and the output directory is the
repo root.

## Files

- `index.html`: page structure and all written content
- `styles.css`: design tokens, layout and components (dark only)
- `script.js`:
  - the field: 8,760 particles on springs, drawn with WebGL (2D canvas if WebGL
    is unavailable), with a camera for the 3D scenes
  - one layout per figure ("scene"), chosen by which block of text crosses the
    middle of the screen (on phones, the middle of the reading area under the
    pinned figure)
  - axes and labels as SVG over the field, tooltips, the skills grid, the menu
    and the copy-email button
- `data.js`: data for the grid-audit figures, generated by `tools/build_data.py`
- `tools/build_data.py`: rebuilds `data.js` from the grid audit
- `assets/`: resume PDF, profile photo, institution logos and icons

## Data behind the figures

- Grid audit ([jinnn11/grid-forecast-audit](https://github.com/jinnn11/grid-forecast-audit)):
  - Hourly demand (the 3D surface and the heat map): EIA-930 adjusted demand for
    2025, summed over the 53 operators the audit scores. 103 missing
    operator-hours (0.02%) take the same hour a day earlier.
  - Operator skill, published and corrected: `results/figures/q1_mape_2025.csv` and
    the audit's "All corrections" variant; bubble size is 2025 demand.
  - California ISO's average day, Southwest Power Pool's daily error and the
    corrected values: computed with the repository's own code (`grid_audit.audit`).
  - National error by year: `results/figures/national_by_year.csv`.
- The other projects: the numbers in each project's README. The CT stack and the
  retraining loop are schematics and say so.

To rebuild `data.js` (from a checkout of the grid audit with its data in place):

```bash
cd ~/code/grid-forecast-audit && .venv/bin/python -I /path/to/this/repo/tools/build_data.py /path/to/this/repo/data.js
```

## Keeping content in sync

When a result changes:

1. Update the text in `index.html`.
2. Update the constants near the top of `script.js` (or rebuild `data.js`).
3. If the resume changes, replace `assets/swaminathan_resume.pdf` and bump the
   `?v=` query on every link to it in `index.html`.
4. After editing `styles.css`, `script.js` or `data.js`, bump their `?v=` query in
   `index.html` so browsers fetch the new files.

Chart colors use a two-series palette (orange for "as published", blue for
"corrected") validated for color-vision deficiency on the dark background; series
identity is always carried by a legend or a direct label, not color alone.
